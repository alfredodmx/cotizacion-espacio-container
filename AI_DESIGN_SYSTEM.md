\# Best Site — AI Design System



\## Core Identity



This SaaS platform uses a premium dark modern interface inspired by:



\* Linear

\* Vercel

\* Raycast

\* Resend



The UI must feel:



\* clean

\* futuristic

\* elegant

\* lightweight

\* highly polished



Avoid generic bootstrap-looking layouts.



\---



\# Tech Stack



\* Next.js

\* Tailwind CSS v4

\* shadcn/ui

\* Framer Motion

\* TypeScript



\---



\# Design Language



\## General Style



\* Dark premium SaaS aesthetic

\* Minimalistic interface

\* High whitespace usage

\* Floating panels/cards

\* Soft shadows

\* Large rounded corners

\* Smooth transitions

\* Professional enterprise feel



\---



\# Color System



Use ONLY semantic colors from the theme tokens.



Never hardcode:



\* bg-black

\* text-white

\* random hex colors



Always use:



\* bg-background

\* bg-card

\* text-foreground

\* text-muted-foreground

\* border-border

\* bg-primary

\* bg-accent



\---



\# Primary Accent



Primary accent uses neon green.



Style:



\* modern AI startup

\* subtle glow

\* never oversaturated



Primary actions should feel energetic but premium.



\---



\# Radius Rules



Use large rounded corners globally.



Preferred:



\* rounded-2xl

\* rounded-3xl



Avoid:



\* sharp corners

\* square cards

\* old UI styles



\---



\# Shadows



Use soft layered shadows.



Preferred:



\* shadow-lg

\* shadow-xl



Shadows should:



\* create depth

\* feel soft

\* never feel heavy



Avoid:



\* hard black shadows

\* aggressive contrast



\---



\# Layout Rules



Dashboard layouts should:



\* breathe

\* use spacing generously

\* avoid clutter

\* feel modular



Use:



\* gap-6

\* gap-8

\* p-6

\* p-8



Prefer:



\* max-w layouts

\* floating containers

\* subtle separators



\---



\# Cards



Cards are the foundation of the interface.



Card style:



\* bg-card

\* border-border

\* rounded-3xl

\* shadow-lg



Cards should feel:



\* soft

\* premium

\* modern

\* slightly elevated



Optional:



\* glassmorphism

\* backdrop blur



\---



\# Buttons



Buttons must:



\* feel smooth

\* have soft hover animations

\* maintain clean typography



Primary buttons:



\* use bg-primary

\* slightly glowing hover

\* no harsh effects



Avoid:



\* thick borders

\* old gradients

\* aggressive animations



\---



\# Tables



Tables should look like modern SaaS dashboards.



Use:



\* subtle borders

\* soft hover states

\* muted separators



Avoid:



\* spreadsheet look

\* dense layouts

\* heavy gridlines



\---



\# Sidebar



Sidebar style:



\* floating dark panel

\* subtle transparency

\* soft border

\* premium spacing



The sidebar should feel:



\* modern

\* lightweight

\* enterprise-ready



\---



\# Typography



Typography should feel:



\* clean

\* modern

\* readable



Use:



\* font-sans

\* medium font weights

\* muted hierarchy



Avoid:



\* excessive bold text

\* tiny text

\* compressed spacing



\---



\# Animations



Use Framer Motion for transitions.



Animations should:



\* be subtle

\* smooth

\* fast

\* premium



Avoid:



\* bounce effects

\* exaggerated motion

\* playful/cartoonish interactions



\---



\# UX Rules



This platform is a professional SaaS product.



Every screen should feel:



\* scalable

\* enterprise-ready

\* polished

\* consistent



Prioritize:



\* clarity

\* hierarchy

\* breathing room

\* consistency



\---



\# Important Development Rule



ALL new components MUST use:



\* semantic theme tokens

\* reusable UI primitives

\* existing spacing/radius system



Never invent new styles outside the design system.



\---



\# Example Component Style



Example card:



```tsx

<Card className="bg-card border-border rounded-3xl shadow-xl">

```



Example button:



```tsx

<Button className="rounded-2xl bg-primary text-primary-foreground hover:opacity-90">

```



Example layout:



```tsx

<div className="min-h-screen bg-background text-foreground">

```
